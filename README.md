# Muhammad — Portfolio

A dependency-free personal landing page built with semantic HTML, modern CSS, and vanilla JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any local static server.

## Deploy to GitHub Pages

1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Under **Source**, select **Deploy from a branch**
4. Choose the branch (e.g., `main`) and `/ (root)` folder
5. Click **Save**

Your site will be live at `https://<username>.github.io/<repository-name>/`

No build step required — GitHub Pages serves the static files directly.

## Project structure

```
.
├── index.html      # Main page
├── css/
│   └── style.css   # Styles with light/dark theme
├── js/
│   └── script.js   # Theme toggle and mobile menu
├── favicon.svg     # Site icon
├── robots.txt      # Search engine crawling rules
├── sitemap.xml     # Search engine sitemap
└── .nojekyll       # Disables Jekyll processing on GitHub Pages
```

## Customisation

Edit `index.html` to update content, contact links, and project URLs.

No third-party libraries, frameworks, or build tools are required.
